⚙️ 多人連線設定

本頁面使用 Firebase Realtime Database(Google 提供,有免費額度)做多人即時同步。 跟本專案的 AI 助手一樣採「自備鑰匙」模式——資料存在你自己的 Firebase 專案裡,不經過任何第三方。

📖 第一次設定?展開教學(約 3 分鐘)
  1. 前往 Firebase 控制台,登入 Google 帳號 → 「建立專案」(名稱隨意,可關閉 Analytics)。
  2. 左側選單 → 建構 → Realtime Database → 「建立資料庫」→ 地區選 asia-southeast1 → 選「以測試模式啟動」。
  3. 回到專案首頁,點 「</> 網頁」 圖示註冊網頁應用程式(不必勾選 Hosting)。
  4. 畫面會出現 const firebaseConfig = { ... },把 大括號整段複製,貼到下面的欄位。
  5. ⚠️ 測試模式的讀寫權限 30 天後會到期。到期前請到 Realtime Database 的「規則」分頁,把 ".read" 和 ".write" 都改成 true(適合班級/小組內部使用;請勿存放敏感資料)。
設定完成後,把「分享連結」傳給同伴,他們不需要再設定——連結裡會自動帶上連線資訊。
